## Code libraries
- **Bootstrap 5.3.3**: MIT licence, https://getbootstrap.com, bundled locally in `vendor/bootstrap/` (downloaded from the jsDelivr CDN). Used for the grid, navbar, carousel and responsive layout.
- **Web Speech API** (`speechSynthesis`): built into modern browsers, used for the read-aloud feature.
- **PHP PDO** and **MySQL**: used for the shop database.

## Information
- Album titles, years, tracklists and band history: general public knowledge, cross-checked with https://www.pinkfloyd.com and Wikipedia's Pink Floyd discography.
- Tour attendance and ticket prices are rounded **estimates** written for this project, and the Tours page says so.
- Case-study structure for the shop (list / add / modify / delete / sort): based on the unit's Session 9 "SneakerStore" case study.
- Acknowledgement of Country wording: adapted from the example given in the assessment brief.
