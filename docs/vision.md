# finalsite: vision

## Problem
NIT1101 Assessment 2 (40%): build a six-page brand website that grows from static HTML into a responsive, interactive, database-driven site. Due Session 10, with an individual demo in Session 11.

## Who it is for
- Marker/demo: every requirement in docs/instructions.md is visibly met and explainable.
- In-story users: Pink Floyd fans, new or old, browsing albums, tours, a fan wall and a merch shop.

## What done looks like
- All checkboxes in docs/instructions.md ticked
- Runs from a fresh machine using site/README.md
- Test report, written report, cover page, contribution statement and acknowledgements done
- Swostik can explain every file in the demo

## Out of scope
Real authentication, payments, a users/reviews/tours database, and hosting online.
